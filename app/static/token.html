What a token is for

The other pages on this site work without one. You need a token only when your own code calls a model through the class endpoint: in a notebook, a script or an app you are building.

Same shape as OpenAI

The endpoint speaks OpenAI's chat completions format, so the openai package works unchanged. You set two values: the address and your token.

Your own allowance

Each token gets 20 requests a minute and 300 a day. The whole class shares one monthly budget, so a loop that runs away hurts everyone.

Treat it like a password

Keep it in an environment variable, never in code you commit. If it leaks, come back here and request a new one: the old one stops working.
